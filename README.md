# TSA-Software-Dev-2026

## Main Purpose
The main purpose of this site is to open barriers with the disabilities of deaf and blind people. We want communication to be efficient for everyone, regardless of boundaries or not. 

## In-Depth
This repository is dedicated to our TSA States (Technosphere) 2026 submission. Our project is centralized to helping both deaf, and blind, people as they navigate their environment with people. It's a more accessible program for people and can be used anywhere, on the go or in a stationary place. We have multiple components:

1. Sign to text
2. Speech to text
3. Text to Speech

## Functionality
- Much of the functions are in our JS folder. The <code>index.js</code> file consists of styling and animations towards the homepage of the website/application. Our real-time translation, audio, and camera/mic accessibility components are stored in the <code>sign.js</code> and <code>speech.js</code> files. 

- All of the UI components and our basic frontend framework is built upon HTML in the <code>SignToText.html</code>, <code>SpeechToText.html</code>, and <code>index.html</code> files. Our styling is connected to our CSS files which provide much of our UI/UX details. Our HTML is connected to our backend JS scripts and CSS styling to have a seamless connection between our frontend and backend portions of our repository.
